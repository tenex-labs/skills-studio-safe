# Workshop walkthrough

Read `docs/runbooks/workshop-demo.md` and run the documented Skill Studio walkthrough.

Use a disposable project for trust and precedence. If a live Claude run is not possible, stop the API
and use the labeled demo catalog, whose runs are simulated.
Exercise Library, trust, precedence conflicts, Editor saves and version history, validation, Test Lab
two-configuration comparison, and run results.

Do not edit production source files.
Do not delete or overwrite personal skills.

Record:

- what the user can do,
- the important states and transitions,
- trust or permission moments,
- confusing behavior,
- unavailable steps or fallback behavior.
